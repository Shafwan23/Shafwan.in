The public sign-in and sign-up pages of myfundbox.com, as they are today

The brief

MYFUNDBOX is a global subscription billing platform: recurring invoices, failed-payment retries, tax rules across regions. As a remote Full Stack Developer Intern, the job was to rebuild core pages of the company website, working across the full stack.

The build

The login and signup flow, built end to end: form validation, error states and session handling. The customer dashboard, developed as responsive, reusable React components. Front-end views connected to Spring Boot REST endpoints, with the loading and error states of every call handled, in a React, TypeScript and Vite codebase with a focus on type safety and clean component structure.

The start

This is where the record begins: authentication flows and dashboard interfaces in React and Spring Boot, and the first taste of owning a feature from the form field to the endpoint.
